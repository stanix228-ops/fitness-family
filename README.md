# VM GYM — Сеть тренажёрных залов в Петропавловске

Официальный сайт сети тренажёрных залов **VM GYM** (@vmgymkz).

- 4 филиала в Петропавловске
- Флагман 24/7 (ул. Карима Сутюшева, 55)
- 34 тренера с прямыми контактами и каталогом
- Актуальные тарифы и абонементы (KZT)
- Интерактивный калькулятор ИМТ и форма записи

## Стек технологий
- HTML5, CSS3, JavaScript (Vanilla ES6+)
- Tailwind CSS
- Font Awesome
- Google Fonts (Oswald, Montserrat)
